API Reference

Integrate with Arbiter's double-entry settlement engine via standard REST APIs. All endpoints require the X-API-Key or x-arbiter-api-key header.

POST /accounts

Initialize a new ledger account with a starting balance.

{
  "accountId": "Treasury:Operating",
  "currency": "USD",
  "openingBalance": "500000.00"
}
POST /payments

Execute a standard ledger payment instruction. Must strictly balance to 0.

{
  "endToEndId": "TX-001",
  "debtorAccountId": "CustomerA",
  "creditorAccountId": "CustomerB",
  "amount": "125.00",
  "currency": "USD",
  "purposeCode": "GDDS"
}
GET /reconcile

Trigger a real-time invariant check across the entire ledger state.

GET /reconcile
X-API-Key: YOUR_KEY
